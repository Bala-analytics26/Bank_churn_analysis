# Bank Customer Churn Analysis and Retention Pilot

SQL analysis of why bank customers leave, with a recommendation and a test plan.

## Question
Who is leaving, and how much money is at risk?

## Key result
Customers aged 46 to 60 with only 1 product are 29.75% of all churn (606 of 2,037).
The recommendation is a 6-month pilot offering them a second product.

## Data
Bank customer churn dataset, 10,000 rows, 14 columns.
Source: Kaggle, 'https://www.kaggle.com/datasets/sidramazam/customer-churn-analysis-dataset'

## Files
- `churn_summary.pdf`: one-page summary. Open this first.
- `churn_analysis.sql`: full SQL analysis (data checks, drivers, deep dive).

## Tools
SQL (PostgreSQL)
